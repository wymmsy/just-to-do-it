# Just To Do It

Список задач на чистом JavaScript (без фреймворков): добавление, редактирование, удаление, отметка выполнения, сортировка по дате, фильтр по статусу, поиск по названию, перетаскивание для изменения порядка, сохранение в localStorage.

## Стек

HTML5, CSS3, vanilla JavaScript (DOM API). Без CSS/JS-фреймворков.

## Структура проекта

```
index.html
css/
  style.css
js/
  data.js
  storage.js
  dom.js
  tasks.js
  app.js
img/
  favicon.svg
```

## Запуск

Открыть `index.html` в браузере.
